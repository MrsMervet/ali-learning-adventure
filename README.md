# رحلة علي بن أبي طالب

إنفوجرافيك تفاعلي من ٨ بطاقات و١٢ تمرينا، ولعبة أكشن: حارس كنز المعرفة، جزيرة واحدة و١٠ مهمات عشوائية.

إعداد المعلمة / ميرفت امين. خط Alexandria مرفق بترخيص OFL.

المحتوى مستخلص من الصفحات ٢٣–٢٨ المرفقة؛ تصميم متجاوب ودعم لوحة المفاتيح والحركة المخفضة.

- index.html: الإنفوجرافيك
- game.html: اللعبة

اللعبة: حركة بالأسهم أو A/D، اندفاع بالمسافة، وأزرار لمس وسحب داخل الساحة للهاتف. تجميع لفائف صحيحة ونجوم، تجنب الصخور، طاقة وفرصة للمتابعة، وضع سرعة هادئة وصوت اختياري.
